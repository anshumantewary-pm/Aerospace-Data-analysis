# Aerospace Data Analysis

> **Status: in progress.** The dataset, notebooks and results have not been uploaded to this
> repository yet. This README describes the planned scope.

## Goal

Analyse aviation and aerospace data to identify patterns in flight operations, delays,
aircraft performance and safety, and present the findings as clear charts and a short report.

## Planned approach

1. Choose and document a public aviation dataset (source and licence will be listed here).
2. Clean and preprocess the data.
3. Exploratory analysis: trends over time, routes, aircraft types, delays and cancellations.
4. Statistical and time-series analysis where the data supports it.
5. Summarise insights on operations, performance and safety.

## Planned tools

Python (pandas, NumPy, matplotlib, seaborn) in Jupyter notebooks; Power BI or Tableau for a
dashboard if useful.
